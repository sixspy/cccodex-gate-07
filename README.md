# 闸口事件湖仓台

码头闸口扫描先落在贴源层，原文照收。建层员选定业务日，按事件字典把扫描收成明细层：进闸、出闸、倒箱。字典里没有的事件码、箱号不合法或时间读不出的扫描留在剔除清单，不进明细。

这里不管堆存量，只处理扫描事件怎么分层。

## 逆序规则

同一箱号出闸时刻早于进闸时刻就是逆序。收成明细前必须先把逆序办法写死，全业务日一个办法，各通道一致，不能有的通道照收、有的通道整组丢掉。

- 逆序办法只能二选一：**整组不进明细**，或**出闸先停在等候队列，等进闸落到贴源后再入库**。
- 办法写进逆序设置后，**当日不许回调**，隔天才能改。
- 逆序还没写死时，这一箱不准收成，其余箱号照常顺收。
- 收成时可以带上办法；带上的办法跟逆序设置不合，记**逆序办法不符**，这组停写。
- 两侧建层员对同一箱号同时下手，抢段加锁后只收下与逆序设置相符的结局，另一边记**逆序争用**。
- 缺进闸或缺出闸的箱号不构成逆序，也不进等候队列。
- 停在等候队列的出闸，确认进闸落到贴源后放行，整组一起进明细。

页面上逆序列表写出箱号、等候条数、丢掉条数、办法名；点开箱号看时序详情，对照进闸时刻与出闸时刻。明细层分开已顺收与逆序未收。
